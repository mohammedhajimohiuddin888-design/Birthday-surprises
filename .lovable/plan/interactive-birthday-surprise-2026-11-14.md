# Interactive Birthday Surprise

## What to build
- Replace the home placeholder with a responsive, three-stage birthday surprise matching the uploaded reference’s cream backdrop, pink cake, and cute cartoon character.
- Require a birthday type and non-empty name before celebration begins.
- Animate the cake, candle flame, automatic 4-to-1 countdown, smoke, personalized character reveal, wishes, and a replay action.

## Technical details
- Keep the experience in the existing `/` TanStack route, using React state and Framer Motion for transitions.
- Draw the cake and character as original inline SVG illustrations; define the palette, typography, and animation styles in the global stylesheet.
- Add page-specific metadata and verify the complete flow on mobile and desktop.
