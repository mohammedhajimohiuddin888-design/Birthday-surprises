# Birthday Surprisefor

Build an Interactive Personalized Birthday Website



Act as a professional frontend developer and creative interaction designer.



Build a complete, responsive, interactive birthday surprise website inspired by the reference video I provided.



IMPORTANT: Do not make an ordinary birthday landing page. Recreate the animated birthday experience.



1. First Screen — Birthday Name Entry



Before showing the birthday cake, create an elegant and cute welcome screen.



Include:



- Heading: "Who's Birthday Is It?"

- Two selection options: Birthday Girl 👸 and Birthday Boy 🤴.

- A text input: "Enter Your Name".

- A button: "Let's Celebrate".

- Beautiful pastel colors, smooth animations and a clean layout.



The visitor must select a birthday type and enter a name before continuing.



2. Second Screen — Animated Birthday Cake



After clicking Let's Celebrate:



- Smoothly transition to a warm cream-colored background.

- Display a cute, hand-drawn cartoon birthday cake.

- Show one pink candle with a flickering flame.

- Display the text "Blow the candle in..."

- Start an animated countdown: 4, 3, 2, 1.

- After the countdown, animate the candle flame going out.

- Show a subtle smoke animation.



The countdown and candle animation must happen automatically.



3. Third Screen — Birthday Surprise



After the candle goes out:



- Show a cute animated cartoon character, similar in style to the reference video.

- Display "Happy Birthday, [NAME]!"

- Add personalized birthday wishes using the entered name.

- Animate the character with cute movements.

- Add small celebratory effects.



4. Design Requirements



- Recreate the minimal, cute, hand-drawn illustration style of the reference.

- Use a warm cream background.

- Use pastel pink accents.

- Use bold, playful typography.

- Keep the illustrations clean and charming.

- Use smooth transitions between every stage.

- Make the experience mobile-first and responsive.



5. Technical Requirements



- React and TypeScript.

- Tailwind CSS.

- Framer Motion for animations.

- Use reusable components.

- Maintain the entered name throughout the entire experience.

- The countdown must run only after the name-entry screen is completed.

- Prevent empty-name submissions.

- Include a replay button to restart the birthday experience.

- Do not use static screenshots as substitutes for animations.

- Do not leave buttons or interactions non-functional.



MOST IMPORTANT



The correct order must always be:



1. Select Birthday Girl or Birthday Boy.

2. Enter the birthday person's name.

3. Click Let's Celebrate.

4. Show the animated cake.

5. Start countdown 4, 3, 2, 1.

6. Blow out the candle.

7. Show the personalized birthday animation and wishes.
